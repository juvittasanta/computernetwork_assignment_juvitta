# Assignment 01

## How the Internet Delivers a Web Page
Website Chosen

Instagram (https://www.instagram.com)

## Objective
The objective of this assignment is to understand how the Internet delivers a web page using Instagram as an example. It explains the TCP/IP protocol stack, the role of DNS, HTTP/HTTPS communication, TCP reliability, client-server architecture, cookies, and the complete communication between a web browser and Instagram's server.

## Solution
A detailed study was conducted on how Instagram loads in a web browser. The assignment explains the functions of each layer in the TCP/IP protocol stack, how DNS converts the domain name into an IP address, how HTTPS requests and responses are exchanged, how TCP provides reliable communication, why Instagram follows the client-server architecture, the differences between HTTP and FTP, the role of cookies, and the complete communication flow between the browser and the server.

## Output
The assignment demonstrates the complete process of accessing Instagram through a web browser. It shows how different Internet protocols work together to securely and reliably deliver Instagram's web pages, images, reels, and other content to the user.

## Conclusion
This assignment helped in understanding how application-layer protocols work together to deliver web pages over the Internet. By studying Instagram, we learned the roles of DNS, HTTPS, TCP, cookies, and the TCP/IP protocol stack in providing secure, reliable, and efficient communication between users and web servers. This knowledge provides a better understanding of how modern web applications function.
